# Third-Party Data Sources

This project includes country-related data compiled from publicly available sources. The data has been transformed, normalized, and adapted for use within this project.

## Data Sources

The country dataset is based on information from the following publicly available sources:

- ISO 3166 country codes
- Wikipedia (country names, official names, capitals, geographical information)
- OpenStreetMap (map references)
- Flagpedia (country flag images)
- MainFacts (coat of arms images)

## Dataset Generation

The country dataset was compiled and normalized from publicly available sources. During the preparation process, AI-assisted tooling was used to help aggregate, transform, and validate portions of the dataset. The resulting data has been reviewed and adapted for use within this project.
